# 👋 안녕하세요, 설미선입니다

> 10년간의 패션업계 경험을 바탕으로 사용자 중심의 가치를 이해하고, 실제 사용자의 니즈를 반영한 웹서비스를 구현하는 프론트엔드 개발자입니다.

## 🚀 주요 프로젝트

### FSF (Full of Soccer Fun)
전세계 인기 축구리그의 실시간 경기정보와 하이라이트를 제공하는 웹 서비스입니다.

#### ✨ 주요 구현 기능
- Next.js Route 기반 서버사이드 렌더링
- Firebase Authentication을 활용한 소셜로그인
- 실시간 데이터베이스 연동으로 사용자데이터관리
- FCM을 활용한 실시간알림 서비스
- Tailwind CSS를 활용한 반응형 디자인과 다크모드지원
- 서버사이드 렌더링으로 초기 로딩 속도 개선

#### 📈 성과
- 뷰어블 라이브러리 의존성 제거로 번들사이즈 42% 감소(2.1MB→1.2MB) 및 페이지 로드 시간 38% 단축
- Firebase 실시간 DB 인덱싱을 활용한 쿼리 응답속도 개선
- TypeScript 93%이상의 도입으로 엄격한 타입체크로 런타임 에러 80% 감소
