# 설미선

> AI 융합 프론트엔드 개발자 (LLM 전문)

14년간의 다양한 업계 경험을 바탕으로 사용자 중심의 가치를 이해하고, AI 기술과 프론트엔드 개발을 융합하여 혁신적인 서비스를 개발하는 개발자입니다.

**현재 LLM 부트캠프 수료 중** (2025.06.18 ~ 2025.11.21)  
RAG, Vector Database, 프롬프트 엔지니어링 등 AI 기술의 실무 활용 능력을 집중적으로 개발하고 있습니다.
